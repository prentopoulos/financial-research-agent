# Ledger financial review

Independently reproduce changed figures from the returned provider records. Verify fiscal period,
unit, sign, scale, shares outstanding, price date, annual-vs-quarterly basis, and formula. Confirm that
FCF is operating cash flow less capital spending, market cap is price times reported shares, and every
multiple handles zero, negative, and missing denominators explicitly.

Peer conclusions must name the peer set, use a correct median, distinguish screening from intrinsic
value, and state material comparability limits. Risk language must point to current primary filings.
Reject any report that hides missing facts, uses stale values without a date, mixes adjusted and GAAP
figures without labeling, or lets an LLM recompute the numbers.

Record the source URLs, retrieval time, inputs, formula, output, tolerance, and reviewer result.
