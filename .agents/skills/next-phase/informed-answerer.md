# Informed answerer brief

Read `PROJECT.md`, `WORKFLOW.md`, `HANDOFF.md`, `AI_OPS.md`, the active OpenSpec change, and the
financial-review skill when relevant. Research only material open decisions. Prefer SEC and provider
documentation, formal standards, and current official framework docs.

For each decision, list the main alternatives, the evidence, later choices it constrains, and whether
the owner must decide. Public data access, paid providers, deployment, retention, external writes,
and trading are always owner calls. Never treat a source document's proposal as an accepted decision.
