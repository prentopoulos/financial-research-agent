# Design skill routing

Ledger UI must stay flat, evidence-first, keyboard accessible, readable at 390px, and free of
simulated product data. Prefer the project's DM Sans, white/cool-grey surfaces, thin rules, explicit
status text, and tabular numbers. Preserve the editorial serif only for research conclusions.

- Use 21st UI search/build for grounded component patterns.
- Use private design source workflows for editable screen designs and code/design synchronization.
- Use design review for accessibility and visual critique.
- Use public-page taste guidance only for art direction; Ledger is a product dashboard.

Every UI change verifies loading, success, unavailable, and error states without invented proof.
