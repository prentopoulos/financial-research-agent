# Ledger decision review

Use this before a phase when requirements are materially ambiguous. Read `PROJECT.md`, `WORKFLOW.md`,
and `HANDOFF.md`. Ask only questions whose answers change scope, data contracts, risk, cost, or the
acceptance evidence. Record resolved decisions in the active OpenSpec change and preserve explicit
non-goals. Do not reopen decisions that the owner has already made.
