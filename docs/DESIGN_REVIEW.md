# Design review

Reviewed on 2026-10-20 against the working desktop and 390 × 844 mobile builds. Three independent
review passes covered visual specificity, accessibility and evidence, and anti-template design taste.
The automated Impeccable detector was unavailable in the installed plugin, so the review used its
craft-floor rubric directly against the rendered product.

## Applied findings

- Added a sticky, scroll-synced mobile report index and a visible horizontal-table cue.
- Kept all search and action controls at least 44 pixels high and repaired the ticker input focus ring.
- Announced provider failures and export completion to assistive technology, with a direct recovery action.
- Replaced decorative technical typography with the product type system and increased evidence metadata sizes.
- Removed the ornamental sparkle, glow, blur, and italic color treatment from the report hero.
- Expanded Markdown export to include the memo, financials, peer comparison, method, model use, trace, and citations.
- Added live/retrieving/failed data states, model fallback reasons, token usage, and failed-step counts.
- Themed selection, caret, focus, and scrollbar browser surfaces from the same visual system.

## Result

The product keeps its editorial research-desk character while making trust signals and recovery states
easy to find. Section numbering remains because it maps directly to the persistent report index and helps
readers navigate a long generated document.
